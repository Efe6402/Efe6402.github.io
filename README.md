# Efe Karakoca — private website draft

This folder contains the complete local website draft. It has not been uploaded or published.

## Structure

- `index.html` — full CV webpage
- `styles.css` — responsive styling
- `theme.js` — accessible light/dark theme control with saved preference
- `assets/efe-karakoca.jpg` — profile photograph with embedded metadata removed
- `EfeKarakoca_CV.pdf` — current CV, linked once at the end of the page
- `papers/` — publication PDFs
- `projects/` — EE 475 and EE 571 course project reports

The website copy of the EE 475 report omits the student identification numbers shown on the original cover. The original document is unchanged.

## Local preview

Open `index.html` directly in a browser, or serve this folder through a local static web server. Keep the folder structure unchanged so the PDF links continue to work.
